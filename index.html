자주 묻는 질문

Liberaflow에 대해 궁금하신 점을 확인해보세요

Liberaflow는 지식을 생성하고 공유하여 업무 혁신을 돕는 AI 워크스페이스입니다.
Note, Space, Mind Map, Calendar, Tasks, Python Automation 등 다양한 도구를 통해 생산성을 극대화할 수 있습니다.
아니요. 작성한 문서와 자동화스크립트는 기본적으로 비공개입니다.
다른 사람과 공유하고 싶을 때 공유하면 됩니다.
Liberaflow는 사용자의 데이터를 학습에 이용하지 않습니다.
따로 저장하지 않은 AI와의 대화는 일정한 주기로 자동 삭제가 되며
LLM 공급업체와의 Zero data retention agreement를 통해 사용자의 데이터를 보호합니다.
macOS와 Windows를 지원합니다. 추후 모바일앱(IOS/Android)도 지원할 예정입니다.
데이터는 클라우드에 안전하게 저장됩니다.
Windows 사용자는 Python 3.8 이상이 설치되어 있어야 합니다. macOS는 Python이 기본 내장되어 있습니다.
현재 베타 버전은 무료로 제공되고 있습니다. 정식 출시 후 가격 정책은 추후 공지될 예정입니다.
