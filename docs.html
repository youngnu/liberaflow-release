00 / QUICK START

처음이라면, 첫 결과물까지 따라 해 보세요

앱 설치부터 AI로 첫 문서를 만들고 확인하기까지 다섯 단계입니다. Liberaflow에 로그인하지 않아도 따라 할 수 있습니다.

  1. 앱을 설치하고 처음 켜면 첫 안내가 나옵니다. 안내에 따라 자료를 둘 보관함(폴더)을 새로 만들거나, 쓰던 마크다운 폴더를 엽니다.
  2. 같은 안내에서 AI 연결 상태를 확인합니다. 연결되어 있지 않다면 쓰고 있는 ChatGPT나 Claude 계정으로 로그인하거나, 설정 → 내 연결에 OpenRouter 키를 넣으세요.
  3. 노트 목록 위의 ‘노트 만들기’ 단추로 새 노트를 만들고, 떠오른 생각을 몇 줄 적습니다. 예: “고객 문의를 유형별로 나눠 담당자에게 넘기는 기능을 만들고 싶다.”
  4. 노트 옆 AI 대화에서 @를 입력해 방금 쓴 노트를 고르고, 원하는 결과를 적어 보냅니다. 예: “이 메모로 기획안 Word 문서를 만들어줘.”
  5. 보관함에 생긴 문서를 열어 확인합니다. 고칠 곳은 짚어서 다시 요청하고, 결과가 마음에 들지 않으면 대화의 ‘이 작업 전으로 되돌리기’를 누르세요.

첫 안내를 다시 보려면 설정 → 정보 → ‘첫 안내 다시 보기’를 누르세요. Liberaflow 로그인은 여러 기기에서 쓰거나 다른 사람과 함께 일할 때 하면 됩니다.

01 / INSTALL

앱 설치하기

화면 설정

운영체제에 맞는 앱을 설치하세요. 로그인 없이 바로 시작할 수 있습니다.

⌘macOS 다운로드macOS 15+ · Apple Silicon↓Windows 다운로드Windows 11 이상↓

macOS 15 이상과 M1 이상의 Apple Silicon, 또는 Windows 11 이상을 지원합니다. 현재 Mac 설치 파일은 Intel Mac용이 아닙니다.

내 눈에 편한 화면으로 바꾸기

설정 → 화면 · 에디터에서 읽기 편한 화면을 맞추세요.

  1. 기본 테마에서 시스템 기본값, 라이트 모드, 다크 모드 중 하나를 선택합니다.
  2. 글자·아이콘 크기로 앱 전체의 크기를 조절합니다. 열려 있는 데스크톱 위젯에는 창을 다시 열면 반영됩니다.
  3. 에디터의 하이라이트 색상으로 이 기기에서 노트의 강조 부분이 보이는 색을 고릅니다. 모든 노트의 하이라이트에 공통으로 적용됩니다.
02 / YOUR VAULT

내 자료가 모이는 보관함

자료 가져오기·정리

보관함은 노트와 작업 자료를 두는 내 컴퓨터의 폴더입니다. 첫 실행에서 보관함을 선택하고 로그인 없이 시작하세요.

  1. 새 보관함을 만들거나 기존 마크다운 폴더를 엽니다. 다른 노트 앱에서 쓰던 폴더도 그대로 열 수 있습니다.
  2. 노트 사이드바 아래의 보관함 스위처에서 보관함을 추가하거나 바꿉니다.
  3. 여러 기기에서 이어서 쓰려면 로그인 후 해당 보관함의 클라우드 동기화를 켭니다.

쓰던 마크다운 폴더와 함께 쓰기

노트는 일반 .md 파일로 저장됩니다. 위키링크·수식·노트 속성을 지원합니다.

LLM Wiki로 자료 정리하기

새 보관함에서 LLM Wiki 스타일을 고르거나, 보관함 관리 → 보관함 스타일 적용에서 추가하세요. /llm-wiki 또는 “위키에 넣어줘”처럼 요청해 원본 자료를 위키로 정리합니다.

파일과 폴더를 가져와 한꺼번에 정리하기

이미 모아둔 자료는 보관함으로 가져와 노트와 같은 폴더에서 관리할 수 있습니다.

  1. 사이드바 위쪽의 파일 삽입을 누르고 가져올 파일을 고릅니다. 여러 파일을 한 번에 선택할 수 있습니다.
  2. 폴더를 통째로 가져오려면 사이드바의 목록이나 대상 폴더로 끌어다 놓습니다. 지원하는 자료를 가져오면서 하위 폴더 구조를 유지합니다.
  3. 정리할 항목을 macOS에서는 ⌘를, Windows에서는 Ctrl을 누른 채 클릭해 함께 선택합니다. 연속된 범위는 첫 항목을 선택한 뒤 Shift를 누르고 마지막 항목을 클릭합니다.
  4. 선택한 항목에서 오른쪽 클릭해 이동을 고르거나, 선택한 항목과 함께 새 폴더 만들기를 사용합니다.

이미지를 노트 본문에 넣으려면 편집 중인 본문 위로 끌어다 놓으세요. Office·HTML 같은 파일을 보관함에 추가할 때는 사이드바를 사용하세요.

03 / WRITE & CONNECT

노트를 만들고, 생각을 연결하기

자료 검색나란히 보기제목으로 연결
  1. 새 노트를 만들고 제목과 내용을 적습니다. 제목·목록·체크박스·표·코드·수식·이미지를 함께 사용할 수 있습니다.
  2. 본문에서 [[ 를 입력하고 연결할 노트를 고릅니다. [[노트 제목]] 형태로 다른 노트와 연결됩니다.
  3. 그래프에서 노트 사이의 연결을 살펴봅니다. 캔버스에는 도형·텍스트·노트를 배치해 관계를 그립니다.
  4. 탭과 분할 화면으로 여러 자료를 오가거나 나란히 보면서 작업합니다.

노트 편집기는 마크다운 저장을 바탕으로 서식을 보여줍니다. 글자 서식과 찾기는 아래 편집 단축키에서 확인하세요.

편집 단축키 보기 →

노트 검색에서 범위 좁히기

어느 노트에 적었는지 기억나지 않을 때는 사이드바의 돋보기, 노트 검색을 여세요.

  1. 제목+본문을 선택하고 기억나는 문구를 입력합니다. 제목만 기억난다면 검색 범위를 제목으로 바꿉니다.
  2. 결과가 많으면 종류를 노트, HTML 또는 캔버스로 좁힙니다.
  3. 로그인한 상태에서는 내 문서, 공유받은 문서, 팀 문서 필터로 자료의 출처를 구분할 수 있습니다.
  4. 결과의 제목과 발췌를 확인한 뒤 필요한 항목을 눌러 엽니다.

캔버스는 제목으로 검색합니다. 캔버스 안의 모든 도형·글자가 본문 검색에 포함되는 것은 아닙니다.

참고 자료와 작성 중인 노트를 나란히 보기

PDF를 읽으며 메모하거나 두 노트를 비교할 때 분할 보기를 사용하세요.

  1. 먼저 참고할 자료를 열고, 위쪽의 해당 탭을 오른쪽 클릭합니다.
  2. 우측 분할을 고르면 자료가 오른쪽에, 하단 분할을 고르면 아래쪽에 열립니다.
  3. 주 편집기에서 작성할 노트로 돌아가 자료를 보며 내용을 적습니다. 각 영역은 따로 스크롤할 수 있습니다.
  4. 가운데 경계를 끌어 읽기 좋은 비율로 조절합니다.

참고 창을 따로 두고 싶다면 탭 메뉴의 새 창에서 열기를 사용합니다.

긴 노트의 특정 제목으로 연결하기

문서 전체보다 특정 부분을 가리키고 싶다면 노트 링크에 제목 위치를 지정하세요.

  1. 예를 들어 연결할 회의록에 결정 사항이라는 제목을 만들어 둡니다. 본문 글자를 굵게만 하는 대신 제목 서식을 적용합니다.
  2. 다른 노트에서 [[를 입력하고 목록에서 회의록을 선택합니다.
  3. 삽입된 노트 링크 바로 뒤에 #을 입력하면 그 노트의 제목을 고르는 창이 열립니다.
  4. 결정 사항을 골라 연결하면 다음에 링크를 눌렀을 때 해당 제목으로 이동할 수 있습니다.

긴 노트를 읽을 때는 제목 위에 마우스를 올려 나타나는 화살표로 아래 내용을 접거나 펼치세요. 접기는 화면 표시만 바꾸며 원문을 지우지 않습니다.

제목 선택 목록에는 제목 서식이 적용된 항목이 나타납니다. 현재 제목 선택기는 제목 1~5를 대상으로 합니다.

04 / DOCUMENT TYPES

어떤 문서를 다룰 수 있나요?

Office 부분 수정주석 달아 고치기

파일 종류마다 보는 방법과 고치는 방법이 다릅니다. 직접 고칠 수도 있고, 고칠 곳을 짚어 AI에게 맡길 수도 있습니다.

마크다운 노트

.md · .markdown

제목·목록·표·코드·수식을 노트 편집기에서 직접 작성합니다. AI에게 노트 읽기·작성·수정도 요청할 수 있습니다.

캔버스

.excalidraw

도형·텍스트·노트를 배치하고 연결선을 그립니다. 캔버스도 보관함 파일로 저장합니다.

HTML

.html · .htm

로컬 HTML을 미리 보고 요소의 텍스트·스타일·배치를 직접 수정합니다. 소스 보기는 읽기 전용이며, 공유받은 원격 HTML도 열람 전용입니다.

PDF

.pdf

앱 안에서 읽고, 텍스트를 검색하고, 확대·축소합니다. AI 대화에 첨부해 분석을 요청하고, 영역을 골라 주석을 달아 보내면 AI가 원본은 그대로 두고 사본을 만들어 고칩니다.

Office와 한글 문서

.docx · .xlsx · .pptx · .hwpx

앱 안에서 미리 보고, 주석을 달거나 부분을 골라 AI에게 원본 수정을 요청합니다. Word·Excel·PowerPoint는 셀·문단을 더블클릭해 직접 고치거나 편집기로 통째로 고칠 수도 있습니다. 한글(HWPX)은 고칠 부분을 골라 요청합니다. 복잡한 서식은 수정 후 확인하세요.

CSV와 TSV

.csv · .tsv

표 형태로 미리 봅니다. 미리보기만으로 원본이 바뀌지는 않습니다.

이미지

PNG · JPEG · GIF · WebP · BMP · SVG · TIFF

이미지를 열어 확대하거나 이동하며 살펴보고, AI 대화의 참고 자료로 첨부합니다. 영역을 골라 주석을 달아 보내면 AI가 원본은 두고 사본을 고칩니다(SVG 제외).

영상

MP4 · MOV · M4V · WebM · MKV · AVI

보관함의 영상을 앱 안에서 재생합니다(MKV·AVI는 컴퓨터의 기본 앱으로 엽니다). AI 대화에 붙이면 AI가 이 컴퓨터의 영상 도구(ffmpeg 등)로 다룹니다. 영상은 이 컴퓨터에만 두며 동기화하지 않습니다.

옛 한글 문서(.hwp)는 처음 한 번 물어본 뒤 같은 자리에 .hwpx로 바꿔 두어 AI가 읽고 고칠 수 있게 합니다. 구형 .doc·.xls·.ppt, Numbers·Keynote 등 인앱 미리보기를 지원하지 않는 형식은 컴퓨터의 기본 앱으로 엽니다. 문서 미리보기가 변환에 실패한 경우에도 외부 앱으로 열 수 있습니다.

Office 문서에서 고칠 부분을 정확히 지정하기

Word·Excel·PowerPoint·HWPX 미리보기에서는 수정할 위치를 먼저 고르면 AI에게 요청을 더 정확히 전달할 수 있습니다.

  1. 문서를 열고 화면 배율에서 읽기 좋은 크기나 화면에 맞추기를 선택합니다. macOS는 ⌘, Windows는 Ctrl을 누른 채 마우스 휠로도 확대·축소할 수 있습니다.
  2. 헤더의 요소 도구를 켜고 수정할 문단이나 셀을 클릭합니다. 여러 요소를 함께 지정하려면 해당 영역을 드래그합니다.
  3. 옆의 AI 대화에 “선택한 문단을 두 문장으로 줄이고, 숫자와 고유명사는 유지해줘”처럼 수정 범위와 조건을 적어 보냅니다.
  4. 작업이 끝나면 갱신된 미리보기에서 결과를 확인합니다. 원본을 외부에서 수정했다면 새로고침으로 다시 읽습니다.

원본 파일 열기를 누르면 연결된 기본 앱에서 실제 문서를 열 수 있습니다.

배율 변경과 선택만으로 파일 내용이 바뀌지는 않습니다. 요소 선택은 AI 요청의 대상을 정하는 기능입니다. 글자를 직접 고치려면 Word·Excel·PowerPoint 미리보기에서 셀이나 문단을 더블클릭하세요.

주석을 달아 여러 곳을 한 번에 고치기

Word·Excel·PowerPoint 미리보기에서는 고칠 곳마다 주석을 남긴 뒤 한 번에 보낼 수 있습니다. PDF와 이미지는 영역을 골라 주석을 답니다.

  1. 문서를 열고 주석 모드를 켭니다. PDF·이미지는 보기 도구줄의 영역 선택 단추를 켜고 끌어서 영역을 지정합니다.
  2. 고칠 곳마다 무엇을 바꿀지 주석으로 적습니다. 예: “이 셀은 14일로”, “이 문단은 두 문장으로 줄여줘.”
  3. 다 적었으면 한 번에 보냅니다. 채널에서는 받을 AI 팀원을 고릅니다. 팀원이 한 명이면 고르지 않아도 됩니다.
  4. AI가 원본 문서를 고치면 미리보기가 다시 그려집니다. PDF와 이미지는 원본을 그대로 두고 같은 폴더에 ‘이름 (수정)’ 사본을 만들어 고칩니다.

파일 전체를 손보려면 미리보기 머리줄의 편집기 단추를 누르세요. Excel·Word·PowerPoint 파일을 앱 안에서 통째로 고치고, 저장하면 바뀐 부분만 원본에 씁니다.

한글(HWPX)은 아직 주석 대신 고칠 부분을 골라 요청합니다. Word·Excel·PowerPoint에서 직접 고친 글자·서식은 원본 파일에 바로 저장되며, 첫 편집 전 원본은 옆에 .bak으로 한 번 보관합니다.

06 / WORK WITH AI

참고 자료를 연결하고 결과물 만들기

질문·승인·되돌리기스킬 만들기

노트 옆 AI 대화에서 ChatGPT(OpenAI)나 Claude 계정으로 로그인하거나, 설정 → 내 연결에 OpenRouter 키를 넣으세요. Liberaflow 로그인과 AI 제공자 로그인은 별개이며, 모델 제공자의 이용 한도와 요금이 적용됩니다.

  1. @를 입력하고 목록에서 참고할 노트·폴더·PDF·이미지·Office 문서를 선택합니다. 파일을 끌어다 놓거나 붙여넣어 첨부할 수도 있습니다.
  2. 원하는 파일 형식과 작업을 구체적으로 요청합니다. 예: “이 회의 메모로 결정 사항과 미정 항목을 구분한 Word 문서를 만들어줘.”
  3. 결과를 미리 보고 필요한 부분을 선택해 수정 요청을 이어갑니다. 파일을 만들었다고 다른 사람에게 자동 공유되지는 않습니다.
  4. 결과가 마음에 들지 않으면 대화의 ‘이 작업 전으로 되돌리기’를 누릅니다. AI가 고친 파일은 고치기 전으로 돌아가고, AI가 새로 만든 파일은 보관함의 .trash 폴더로 이동합니다.

@로 문서·폴더 연결하기

AI 입력창에서 @ 뒤에 찾을 이름을 입력하고, 목록에서 문서나 폴더를 선택하세요. 선택한 자료를 언급한 상태로 원하는 작업을 이어서 적습니다.

노트·폴더뿐 아니라 PDF·이미지·Office 문서도 참고 자료로 연결할 수 있습니다.

# 목록에서 역할을 가진 AI 팀원 선택

OpenRouter 키는 Liberaflow 로그인 없이도 쓸 수 있고 이 컴퓨터에만 저장됩니다. Liberaflow에 로그인하면 지식 공간(Spaces) 검색도 사용할 수 있습니다. 반복해서 쓰는 작업은 에이전트 스킬로 만들고 /스킬명으로 실행할 수 있습니다.

AI 응답에는 네트워크 연결이 필요합니다. 요청에 필요한 자료와 대화 맥락이 선택한 모델 제공자에게 전달됩니다.

AI가 묻거나 허락을 구할 때

AI가 작업 방향을 물으면 입력창 자리에 질문이 나타납니다. 방향키로 보기를 고르고 Enter를 누르거나, 직접 적어서 ‘답변 보내기’를 누르세요. Esc를 누르면 작업이 그 자리에서 멈춥니다. 계획 모드(Plan Mode)에서는 AI가 파일을 만들거나 고치지 않습니다. 파일 작업까지 맡기려면 입력창에 /plan off를 입력해 계획 모드를 끈 뒤, 같은 대화에서 다시 요청하세요.

권한을 ‘편집 전 승인’으로 두면, AI는 파일을 바꾸거나 인터넷에 접속하기 전에 매번 승인 카드를 띄웁니다. 이 승인 카드는 ChatGPT(OpenAI)나 OpenRouter 모델로 대화할 때 나타납니다. 바뀔 파일과 실행할 명령을 확인한 뒤 ‘허용’, ‘이 대화에서 계속 허용’, ‘거절’ 중 하나를 누르세요. 거절하면 AI는 그 일만 빼고 다른 방법으로 이어 갑니다.

되돌리기는 AI가 고치거나 만든 파일에만 적용됩니다. 그 사이 내가 직접 고친 다른 파일은 그대로 남습니다. 셸 명령처럼 기록 없이 바뀐 파일은 되돌릴 수 없으며, 그런 파일이 있으면 앱이 알려 줍니다.

반복해서 쓰는 작업 방식을 스킬로 만들기

매번 길게 설명하던 작업 순서와 결과물 기준을 스킬로 정리해 두면 다음 AI 대화에서 다시 사용할 수 있습니다.

  1. 에이전트 → Skills에서 만들기를 누르면 Notes의 스킬 생성 대화가 열립니다.
  2. 언제 쓸 스킬인지, 어떤 자료를 받을지, 결과물을 어떻게 정리할지 설명합니다.
  3. 예를 들어 “회의 메모를 결정 사항·담당자·기한 순서로 정리하는 스킬을 만들어줘”라고 요청할 수 있습니다.
  4. AI가 물어보는 사용 예시와 기준을 보완하며 같은 대화에서 내용을 다듬습니다.
  5. 완료 후 Skills의 이 기기의 스킬에서 확인하고, AI 입력창에 /를 입력해 해당 스킬을 선택한 뒤 이번 작업을 요청합니다.

이미 만든 스킬이 있다면 설치를 누르고 SKILL.md가 들어 있는 폴더를 선택할 수 있습니다.

목록의 스킬을 누르면 파일과 내용을 열어 볼 수 있으며, 이 동작만으로 스킬이 실행되지는 않습니다.

Plan Mode가 켜져 있으면 실제 설치 전에 끄고 같은 대화에서 이어가세요. 이 기기에 설치한 스킬은 다른 기기로 자동 동기화되지 않습니다.

문서 공유

Liberaflow에 로그인하고 보관함의 클라우드 동기화를 켠 뒤, 문서의 공유 창에서 사람이나 팀을 선택합니다. 공유한 노트는 작성자의 것으로 남고, 공유를 해제하면 접근을 거둘 수 있습니다.

AI 팀원 설정하기

사이드바의 에이전트 화면에서 AI 팀원을 관리합니다. 처음부터 CEO, Reviewer, Worker 세 팀원이 있습니다. 카드에서 이름·역할 지시문·실행 모델을 고치거나 새 팀원을 만들 수 있습니다. 팀원을 부를 때는 노트 옆 AI 대화나 채널에서 #이름을 입력합니다.

채널에서 AI 팀원과 일하기

채널은 사람과 AI 팀원이 함께 쓰는 대화방입니다. 왼쪽 메뉴의 Channel에서 Local과 Cloud를 오갑니다.

  1. Local 채널은 Liberaflow에 로그인하지 않고도 이 컴퓨터에서 쓸 수 있습니다. 채널을 만들 때 함께할 AI 팀원을 확인하세요. 처음에는 사용 중인 팀원이 모두 선택되어 있습니다. 나중에 더 넣으려면 팀원 관리 창의 ‘팀원 추가’를 쓰세요. 대화, 채널 메모, 팀원의 기억은 이 컴퓨터에만 저장됩니다.
  2. 사람과 함께 쓰려면 로그인한 뒤 Cloud에서 팀 채널이나 개인 채널을 만듭니다. AI 팀원은 채널 관리자만 넣을 수 있습니다. 넣을 때는 멤버 창의 ‘AI 팀원 초대’를 누릅니다.
  3. Cloud 채널에서 자료를 함께 보려면 채널 메뉴의 ‘내 문서 채널에 공유’로 문서를 올린 뒤, 입력창의 @ 목록에서 고릅니다.
  4. # 목록에서 AI 팀원을 고르고 할 일을 적습니다. AI 팀원을 부르지 않은 글은 사람들에게만 전달됩니다.
  5. 여러 팀원을 한 번에 부르면 함께 일합니다. 팀원이 답변에 다른 팀원의 #이름을 적으면 그 팀원에게 일을 넘깁니다.
  6. 대화에서 합의한 조건과 결정은 AI 팀원이 채널 메모에 정리합니다. 대화 오른쪽 패널의 ‘채널 메모’에서 확인하세요.

채널의 @ 목록에는 멤버가 접근할 수 있는 공유 문서가 표시됩니다. 채널 AI는 호출한 사람의 컴퓨터와 모델 연결로 실행됩니다.

지식 공간에서 팀 자료 찾기

로그인하면 문서·노트·웹페이지·유튜브 영상을 지식 공간(Spaces)에 모을 수 있습니다. 정확한 단어가 기억나지 않아도 관련 자료를 찾고, 근거와 함께 답을 받습니다. AI 대화에 지식 공간을 연결해 자료를 참고할 수도 있습니다.

채널에 코딩 프로젝트 연결하기

아이디어가 프로젝트가 되면 채널에 코드 폴더를 연결하세요. 채널의 AI 팀원이 그 코드를 읽고 고치며, 바뀐 줄을 보여 줍니다.

  1. 채널 대화 오른쪽 패널 맨 위의 코딩 프로젝트 카드에서 코딩 프로젝트 연결을 누릅니다. Local 채널은 내 컴퓨터의 코드 폴더를 고르고, Cloud 채널은 GitHub 저장소 연결과 로컬 폴더 연결 중 하나를 고릅니다.
  2. 연결하면 카드에 폴더·브랜치와 열기·터미널이 생기고, 파일·변경· 최근 커밋을 대화를 떠나지 않고 그 자리에서 봅니다. 입력창에서 @를 치면 프로젝트의 파일을 골라 붙일 수 있습니다.
  3. # 목록에서 AI 팀원을 불러 할 일을 적습니다. 예: “이 기획대로 분류 기능을 만들고, 테스트가 통과하면 커밋해줘.” 팀원이 파일을 고치면 바뀐 줄이 diff 카드로 보입니다.
  4. 커밋은 부탁할 때만 합니다. 혼자 쓰는 채널에서는 연결한 폴더에서 바로 고치고, “커밋 푸시”를 부탁하면 지금 브랜치에 커밋해 올립니다.
  5. 다른 사람과 함께 쓰는 채널에 Git 저장소를 연결했다면, 저장소 옆의 AI 전용 작업 폴더에서 새 브랜치를 만들어 일하므로 내 작업과 섞이지 않습니다. “커밋 푸시”를 부탁하면 브랜치를 올리고 PR을 열어 두며, 동료가 PR 카드에서 검토하고 병합합니다. Git 저장소가 아닌 폴더는 어느 채널에서든 연결한 폴더에서 바로 고칩니다.

팀 채널 관리자가 GitHub 저장소를 채널에 걸어 두면, 멤버는 오른쪽 패널의 이 컴퓨터에서 준비 카드에서 같은 코드를 내 컴퓨터로 받거나 이미 받아 둔 폴더를 연결합니다.

PR을 열고 병합하는 일은 이 컴퓨터의 GitHub CLI로 하므로 gh auth login을 해 두세요. 팀원에게 기본 브랜치에 올리지 말라고 일러 두지만 앱이 막는 것은 아니므로, 실제로 막으려면 GitHub에서 기본 브랜치 보호를 켜 두세요. 연결한 폴더 경로는 이 기기에만 저장됩니다.

공유받은 노트에 수정 제안하기

로그인한 뒤, 사이드바의 공유받은 문서 또는 팀 섹션에서 검토할 노트를 엽니다. 예를 들어 팀의 행사 계획서에서 일정과 준비물만 고치고 싶을 때 이 흐름을 사용하세요.

  1. 노트에서 바꿀 부분을 수정하고, 하단의 병합 요청 버튼을 누릅니다. 일반 공유 수신자가 작성한 수정안은 이 단계에서 원본에 바로 저장되지 않습니다.
  2. 병합요청 생성 창에 제목과 설명을 적고 저장합니다. “회의 날짜 변경과 준비물 추가”처럼 무엇을 바꿨는지 적으면 검토하는 사람이 판단하기 쉽습니다.
  3. 작성자 또는 해당 노트의 매니저가 변경을 확인하고 병합합니다. 팀 관리자 역할만으로 다른 사람의 노트를 직접 저장할 수 있는 것은 아닙니다.
HTML·Office 미리보기 공유본 갱신하기

HTML·Office 미리보기 공유본은 공유 시점의 사본이므로, 원본을 고친 뒤 미리보기를 열고 공유 창을 다시 확인해 최신 내용으로 갱신하세요. 기존 공유 링크와 받는 사람은 유지됩니다.

채널 메모로 결정과 근거 확인하기

채널 메모는 채널의 사람과 AI 팀원이 함께 보는 작업 기록입니다. 팀원마다 대화가 따로 이어지기 때문에, 모두가 알아야 할 조건과 결정은 이곳에 모입니다. 메모는 AI 팀원이 일하면서 직접 적고, 다음에 불릴 때 다시 읽습니다. 새 메모를 만드는 버튼은 따로 없습니다.

채널 메모의 종류
종류 담는 내용 예
조건 지켜야 할 제약이나 사실 예산은 100만 원 이내
결정 정해진 내용과 끝난 작업 행사 장소는 2층 회의실
진행 상황 요청했지만 아직 끝나지 않은 일 초대장 초안 검토 중

진행 상황에 있던 일이 끝나면 AI 팀원이 결정으로 옮겨 적습니다.

  1. 대화 오른쪽 패널에서 ‘채널 메모’를 누릅니다. 패널이 닫혀 있으면 오른쪽 위의 ‘채널 자료 열기’를 먼저 누르세요. Cloud 채널에서는 채널 메뉴로도 열 수 있습니다.
  2. ‘메모 내용 검색’에 “행사 장소”처럼 찾을 말을 입력하거나, 전체·조건·결정·진행 상황 중 하나를 고릅니다. 메모가 아직 없다면 채널에서 AI 팀원에게 “중요한 내용을 채널 메모로 정리해줘”라고 요청하세요.
  3. 메모의 제목 줄을 누르면 전체 내용이 펼쳐집니다. 본문의 링크를 누르면 근거가 된 채널 대화의 원문이 열립니다. 요약한 날짜나 수치가 원문과 같은지 확인해 보세요.
  4. 잘못 적힌 내용은 ‘메모 수정’으로 바로잡고 저장합니다. 필요 없어진 메모는 ‘메모 삭제’로 지웁니다. 메모를 지워도 근거가 된 채널 대화는 그대로 남습니다.

새로운 결정이나 요청은 메모를 고치기보다 채널 대화에 남기세요. 그래야 다른 멤버와 AI 팀원도 알 수 있습니다. Cloud 채널에서는 메모를 고치거나 지우는 버튼이 채널 관리자에게만 보이고, 다른 멤버에게는 ‘관리자만 수정·삭제’가 표시됩니다.

AI 팀원의 채널 기억 확인하기

AI 팀원은 채널마다 따로 기억을 남깁니다. 채널 메모가 모두의 작업 기록이라면, 팀원의 기억에는 그 팀원이 이 채널에서 어떻게 일할지가 담깁니다. 같은 채널의 같은 팀원은 누가 부르든 같은 기억을 이어 씁니다. 진행 중인 일은 기억이 아니라 채널 메모에 남습니다.

  1. 대화에서 AI 팀원의 이름이나 아바타를 누릅니다. Cloud 채널에서는 멤버 목록에서 팀원을 골라도 됩니다. 오른쪽에 팀원 정보가 열립니다.
  2. Memories 탭을 고릅니다. 위쪽 Ground에는 이 채널에서 맡은 역할, 사람들이 바라는 방식, 지켜야 할 규칙이 한 장에 적혀 있습니다. 아래쪽 Cards에는 오래 기억할 사실이나 교훈이 한 장에 하나씩 담깁니다.
  3. 잘못 적힌 기억은 ‘기억 수정’으로 바로잡습니다. 더는 필요 없는 카드는 ‘기억 삭제’로 지웁니다.

원하는 보고 방식이나 지켜야 할 규칙을 채널에서 말해 두면, 팀원이 이를 기억에 적고 다음 대화에서도 따릅니다. 고친 Ground는 팀원이 새 대화를 시작할 때부터 반영됩니다. 앱을 다시 켠 뒤 팀원을 부르거나, 그 팀원의 이전 작업이 끝나고 30분 넘게 지나서 다시 부르면 새 대화가 시작됩니다.

지식 공간에 자료를 모아 질문하기

Liberaflow에 로그인한 뒤 Spaces에서 공간 만들기를 선택합니다. “신규 입사자 안내”처럼 용도가 드러나는 제목과 설명을 적고 계속을 누르세요.

  1. 콘텐츠 추가에서 참고할 자료를 모읍니다. 파일과 노트는 고르고, 웹페이지는 주소를, 유튜브 영상은 링크를 붙여 넣습니다. 선택된 콘텐츠 목록을 확인하고 추가를 누른 뒤 처리가 끝날 때까지 기다리세요.
  2. 노트 옆 AI 대화에서 스페이스 검색을 켜고 이번 질문에 사용할 공간을 선택합니다. 선택한 스페이스에서 검색이라는 입력 안내가 보이면 “휴가 신청 절차를 정리하고 근거 문서를 알려줘”처럼 질문하세요.
  3. 답변과 함께 제시된 근거를 확인하고, 필요한 조건을 더해 질문을 좁힙니다. 예를 들어 “신입 직원에게 적용되는 절차만 체크리스트로 바꿔줘”라고 이어갈 수 있습니다.
나만 쓸 공간과 함께 쓸 공간 나누기

누가 볼지는 공간을 만들거나 고치는 창의 공개 설정에서 정합니다. 비공개는 나만 볼 수 있고, 멤버만은 지정한 사람이, 조직은 지정한 팀이 볼 수 있습니다.

Spaces는 로그인과 인터넷 연결이 필요한 지식 검색 기능이며, 보관함 동기화를 켜지 않아도 사용할 수 있습니다.

알림 센터와 채널 배지 정리하기

로그인 후 알림 화면에서 공유·초대·멘션 등 협업 알림을 확인합니다. 예를 들어 팀 초대나 나를 부른 채널 글을 놓쳤다면 여기서 해당 항목을 열어보세요.

  1. 상단 필터에서 읽지 않음을 골라 아직 확인하지 않은 항목을 모읍니다. 처리가 끝났다면 모두 읽음 처리를 사용해 목록을 정리할 수 있습니다.
  2. 채널 알림을 누르면 관련 메시지 자리로 이동합니다. 채널을 열어 읽으면 해당 채널의 읽지 않은 배지도 정리됩니다.
  3. 메시지가 많은 채널은 채널 메뉴의 알림 끄기로 일반 글의 배지를 숨깁니다. 이 설정은 다른 기기에도 적용되지만, 나를 부른 글의 호출 알림은 계속 받을 수 있습니다.

설정 → 시스템 · 알림에 있는 ‘채널 호출·AI 완료 알림’은 누가 나를 #으로 부르거나 내가 요청한 AI 답변이 끝났을 때 알려 주는 설정입니다. 다른 화면을 보고 있거나 앱이 뒤에 있을 때 알림이 옵니다. 이 설정을 끄면 두 알림이 모두 오지 않습니다. 일반 글은 배지로만 표시되며, 채널 메뉴의 ‘알림 끄기’와는 따로 동작합니다.

08 / CALENDAR & TASKS

내 일정부터 함께 보는 일정까지

회의·프로젝트바탕화면 위젯예약 만들기·종료
  1. Calendar에서 날짜를 누르고 제목·시작·종료 시간을 정해 일정을 만듭니다.
  2. Tasks의 오늘의 할일에서 할 일을 추가하고 끝낸 항목을 완료로 표시합니다. 개인 일정과 할 일은 로그인 없이 시작할 수 있습니다.
  3. 함께 보려면 로그인 후 설정 → 팀에서 팀을 만들고 멤버를 초대하거나, 설정 → 사람에서 팔로우를 요청합니다. 상대가 수락하면 연결됩니다.
  4. Calendar에서 내 일정과 같은 팀·팔로우한 사람의 공개 일정을 한 화면에 봅니다. 같은 팀이면 별도 팔로우가 필요하지 않습니다.

공개 일정은 팔로워·같은 팀원에게, 비공개 일정은 작성자와 지정한 참석자에게만 표시됩니다.

Calendar 왼쪽 패널에서 캘린더·프로젝트·메모·루틴·예약·맞춤 보기를 오갑니다. 매일 챙길 일은 루틴에 적어 두고 날마다 체크합니다. 맞춤 보기에서는 필요한 패널을 원하는 자리에 놓을 수 있습니다.

일정도 AI에게 말로 맡길 수 있습니다. 노트 옆 AI 대화나 채널에서 “목요일 2시에 디자인 리뷰 잡아줘”처럼 요청하세요.

바탕화면과 프로젝트에서도

일정·할 일·프로젝트 간트 타임라인을 연결해 관리합니다. 할 일·스티키 메모·캘린더는 독립된 데스크톱 위젯으로 띄울 수 있습니다.

AI 작업 예약하기

Calendar의 예약에서는 AI 작업을 한 번만 실행하거나 매일·매주 반복하도록 정할 수 있습니다. AI 대화에서 “매주 월요일 9시에 주간 보고 초안을 만들도록 예약해줘”처럼 말해 예약을 만들 수도 있습니다. 앱이 켜져 있어야 실행되며, 실행 기록에서 결과와 실패 사유를 확인할 수 있습니다.

앱이 꺼져 있어 놓친 예약은 24시간 이내인 경우 다음 실행 때 처리합니다. 24시간을 넘긴 예약은 실패로 기록됩니다.

회의 일정과 프로젝트 할 일 맞추기

한 시간짜리 회의를 준비한다면 Calendar에서 날짜를 누르고 제목·위치·메모를 먼저 적습니다. 시간 묶음에서 시작 날짜와 시간을 각각 누른 뒤 길이를 1시간으로 고르면 종료 시간을 빠르게 맞출 수 있습니다.

  1. 하루 전체를 비워 둘 일정은 종일을 켭니다. 시작 시각을 바꿔도 기존 일정 길이는 유지되므로 종료 시각까지 확인한 뒤 저장하세요.
  2. 로그인한 상태에서는 상세의 참석자에서 함께할 사람을 고릅니다. 참석자에게만 보일 회의는 공개 범위를 비공개로 지정하세요.
  3. 알림에서 30분 전 같은 시점을 고르고, 다른 간격이 필요하면 사용자 지정을 사용합니다. macOS에서 알림 시각을 처음 고르면 알림 허용 창이 뜨니 허용하세요. 전에 허용하지 않았다면 앱이 시스템 설정을 열어 주므로 그곳에서 Liberaflow의 알림을 켭니다.
프로젝트 업무를 오늘의 할 일과 연결하기

프로젝트의 간트 타임라인에서는 업무의 담당자와 참여자를 지정하고 날짜를 조절할 수 있습니다. 하위 업무가 없는 오늘 날짜의 작업 중 내가 담당자나 참여자인 항목은 오늘의 할일에도 나타납니다. 같은 일정과 연결된 작업은 완료 여부와 날짜가 함께 반영되므로, 한 화면에서 바꾼 뒤 다른 화면에서도 확인해 보세요.

할 일과 메모를 바탕화면에 꺼내두기

macOS와 Windows에서는 캘린더·할 일·메모를 각각 독립 창으로 띄울 수 있습니다. 개인 위젯은 Liberaflow에 로그인하지 않아도 사용할 수 있습니다.

  1. Calendar의 캘린더를 데스크톱 위젯으로 버튼을 누르면 달력만 따로 열립니다. 날짜를 누르고 일정을 확인하거나 수정할 때 사용하세요.
  2. 넓은 화면의 Tasks 패널에서 Tasks 창 분리를 누르면 할 일 창이 열립니다. 메모는 카드의 더보기 메뉴에서 위젯으로 띄우기를 선택하세요.
  3. 창을 원하는 위치와 크기로 옮기고, 투명도 조절로 다른 작업 화면과 함께 보기 편하게 맞춥니다. 다음 앱 실행 때 다시 열고 싶으면 창의 핀 버튼을 켜세요.

핀은 앱 시작 시 자동 복원을 설정하는 기능이며, 창을 항상 맨 위에 두지는 않습니다. 위젯을 직접 닫으면 자동 복원 설정도 해제되므로, 다음에도 쓰려면 다시 열고 핀을 켜세요.

예약할 자료와 시간을 정하고, 다음 실행 관리하기

예약 작업에도 참고할 자료와 원하는 결과를 함께 적어 두세요.

  1. Calendar 왼쪽 패널의 예약에서 예약 만들기를 누릅니다.
  2. 작업 지시를 입력하고, 필요한 노트·PDF·폴더·파일은 @로 찾아 선택합니다.
  3. 사용할 AI를 고른 뒤 실행 주기를 한 번·매일·매주 중에서 선택합니다.
  4. 한 번은 날짜와 시간을, 매일은 시간을, 매주는 요일과 시간을 정한 뒤 예약을 누릅니다.
  5. 예정 · 반복 목록에서 다음 실행을 확인하고, 기록에서 완료 결과의 요약이나 실패 사유를 확인합니다.

대기 중인 단발 작업은 예약 취소로, 반복 작업은 반복 종료로 앞으로의 실행을 취소할 수 있습니다.

시간이나 지시를 바꾸려면 기존 대기 예약을 취소하거나 반복을 종료한 뒤 새 예약을 만드세요.

반복을 종료해도 이미 끝난 실행의 기록은 남습니다. 예약에 사용하는 AI 계정이 연결되어 있는지도 확인하세요.

09 / STORAGE & SYNC

로컬 저장, 동기화, 공유 구분하기

저장 상태·복구

기본 작업 공간은 내 컴퓨터의 보관함입니다. 클라우드 동기화는 보관함별로 켜고, 다른 사람에게 공유할 자료는 따로 선택합니다.

저장과 공유 범위
자료 동기화와 공유
노트·캔버스 동기화를 켜면 내용과 삭제가 다른 기기에 반영됩니다. 노트는 사람·팀을 지정해 공유하고, 캔버스는 공개 설정 또는 팀 공유를 사용합니다.
PDF 비공개 파일로 동기화합니다. PDF 자체의 공유 기능은 제공하지 않습니다.
HTML 비공개 파일로 동기화합니다. 멤버 공유를 선택하면 공유 시점의 사본을 전달합니다.
Office·CSV·영상·코드 등 그 밖의 파일 이 컴퓨터에만 두며 클라우드로 동기화하지 않습니다. 다른 기기에서 쓰려면 파일을 직접 옮기세요.

노트에 삽입한 이미지도 동기화됩니다. 보관함에 따로 놓은 이미지 파일 전체가 동기화되는 것은 아닙니다.

삭제와 복구

클라우드 동기화한 노트·캔버스는 삭제가 다른 기기에도 반영되며 30일 안에 복구할 수 있습니다. PDF·HTML은 클라우드에서도 바로 삭제되고 별도 휴지통이 없습니다.

로컬 보관함의 휴지통·백업은 클라우드 복구와 별개입니다. 중요한 원본은 별도로 백업하고, 삭제할 때는 파일 종류와 동기화 상태를 확인하세요.

저장 상태가 평소와 다를 때 확인하기

클라우드 동기화를 쓰는 노트는 이 기기의 저장과 다른 기기의 반영 상태를 함께 확인하세요.

  1. 노트 속성 바에 클라우드 반영 대기가 나타나면 이 기기에 저장된 내용이 아직 다른 기기나 공유 대상에 반영되지 않은 상태입니다.
  2. 상태 표시에 마우스를 올려 설명을 읽고, 네트워크와 로그인 상태를 확인합니다.
  3. 저장 실패가 나타나면 안내를 확인하고 중요한 내용을 따로 복사해 둡니다. 임시 보관된 내용이 있다는 안내와 클라우드 저장 완료는 구분해야 합니다.
  4. 다시 열 때 임시 저장된 내용 발견 창이 표시되면 노트 이름과 마지막 임시 저장 시각을 확인합니다. 미저장 변경을 이어서 쓰려면 복구를 선택합니다.

복구 안내는 남아 있는 임시본이 있을 때 표시되며 모든 보관함에서 항상 나타나는 화면은 아닙니다. 삭제한 문서를 되살리는 휴지통과도 별개의 기능입니다.
