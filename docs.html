노트편집 명령어

단축키 / 명령어 설명
/ 슬래시 명령어
@ 노트 간 연결 (제텔카스텐 링크)
Ctrl / Cmd + Z 실행취소
# + 스페이스바 제목 1
## + 스페이스바 제목 2
### + 스페이스바 제목 3
#### + 스페이스바 제목 4
##### + 스페이스바 제목 5
> + 스페이스바 인용구
``` + 스페이스바 코드블록
[ ] + 스페이스바 할 일 목록 (체크리스트)
- 또는 * + 스페이스바 불릿 리스트
1. + 스페이스바 숫자 리스트
Tab 들여쓰기
Shift + Tab 내여쓰기
블록선택 후 Ctrl / Cmd + B 굵게 (Bold)
블록선택 후 Ctrl / Cmd + U 밑줄 (Underline)
블록선택 후 Ctrl / Cmd + I 기울임꼴 (Italic)
블록선택 후 Ctrl / Cmd + Shift + S 취소선 (Strikethrough)
