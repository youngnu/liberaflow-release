운영체제에 맞는 앱을 설치하세요. 현재 베타 기간에는 무료로 시작할 수 있습니다.

macOS 15 이상과 M1 이상의 Apple Silicon, 또는 Windows 11 이상을 지원합니다. 현재 Mac 설치 파일은 Intel Mac용이 아닙니다.

02 / YOUR VAULT

내 자료가 모이는 보관함

보관함은 노트와 작업 자료를 두는 내 컴퓨터의 폴더입니다. 첫 실행에서 보관함을 선택하고 로그인 없이 시작하세요.

  1. 새 보관함을 만들거나 기존 마크다운 폴더를 엽니다. Obsidian에서 사용하던 폴더도 열 수 있습니다.
  2. 노트 사이드바 아래의 보관함 스위처에서 보관함을 추가하거나 바꿉니다.
  3. 여러 기기에서 이어서 쓰려면 로그인 후 해당 보관함의 클라우드 동기화를 켭니다.

Obsidian과 함께 쓰기

노트는 일반 .md 파일로 저장됩니다. 위키링크·수식·노트 속성을 지원하지만, Obsidian의 플러그인과 앱 전용 기능까지 모두 호환되지는 않습니다.

LLM Wiki로 자료 정리하기

새 보관함에서 LLM Wiki 스타일을 고르거나, 보관함 관리 → 보관함 스타일 적용에서 추가하세요. /llm-wiki 또는 “위키에 넣어줘”처럼 요청해 원본 자료를 위키로 정리합니다.

03 / WRITE & CONNECT

노트를 만들고, 생각을 연결하기

  1. 새 노트를 만들고 제목과 내용을 적습니다. 제목·목록·체크박스·표·코드·수식·이미지를 함께 사용할 수 있습니다.
  2. 본문에서 [[ 를 입력하고 연결할 노트를 고릅니다. [[노트 제목]] 형태로 다른 노트와 연결됩니다.
  3. 그래프에서 노트 사이의 연결을 살펴봅니다. 캔버스에는 도형·텍스트·노트를 배치해 관계를 그립니다.
  4. 탭과 분할 화면으로 여러 자료를 오가거나 나란히 보면서 작업합니다.

노트 편집기는 마크다운 저장을 바탕으로 서식을 보여줍니다. 글자 서식과 찾기는 아래 편집 단축키에서 확인하세요.

04 / DOCUMENT TYPES

어떤 문서를 다룰 수 있나요?

파일 종류마다 보는 방법과 수정 방법이 다릅니다. 노트처럼 직접 편집하는 문서와, 미리보기를 보며 AI에게 수정을 요청하는 문서를 구분해 사용하세요.

마크다운 노트

.md · .markdown

제목·목록·표·코드·수식을 노트 편집기에서 직접 작성합니다. AI에게 노트 읽기·작성·수정도 요청할 수 있습니다.

캔버스

.excalidraw

도형·텍스트·노트를 배치하고 연결선을 그립니다. 캔버스도 보관함 파일로 저장합니다.

HTML

.html · .htm

로컬 HTML을 미리 보고 요소의 텍스트·스타일·배치를 직접 수정합니다. 소스 보기는 읽기 전용이며, 공유받은 원격 HTML도 열람 전용입니다.

PDF

.pdf

앱 안에서 읽고, 텍스트를 검색하고, 확대·축소합니다. AI 대화에 첨부해 분석을 요청할 수 있습니다. PDF 본문을 직접 편집하는 화면은 아닙니다.

Office와 한글 문서

.docx · .xlsx · .pptx · .hwpx

앱 안에서 미리 보고 부분을 선택해 AI에게 원본 수정을 요청합니다. 미리보기에서 직접 타이핑하거나 셀을 편집하는 방식은 아닙니다. 복잡한 서식은 수정 후 확인하세요.

CSV와 TSV

.csv · .tsv

표 형태로 미리 봅니다. 미리보기만으로 원본이 바뀌지는 않습니다. 브라우저 자동화의 수집 결과는 CSV 또는 XLSX로 내보낼 수 있습니다.

이미지

PNG · JPEG · GIF · WebP · BMP · SVG · TIFF

이미지를 열어 확대하거나 이동하며 살펴보고, AI 대화의 참고 자료로 첨부합니다. 원본 이미지를 직접 수정하는 편집기는 제공하지 않습니다.

구형 .hwp·.doc·.xls·.ppt, Numbers·Keynote 등 인앱 미리보기를 지원하지 않는 형식은 컴퓨터의 기본 앱으로 엽니다. 문서 미리보기가 변환에 실패한 경우에도 외부 앱으로 열 수 있습니다.

기호 대신 삽입 메뉴로 고르기

빈 본문 줄에서 /를 입력하면 삽입 메뉴가 열립니다. Space 없이 ↑·↓로 항목을 고르고 Enter로 적용하세요. Esc로 메뉴를 닫습니다.

글자를 **굵게**, *기울임*, ~~취소선~~처럼 감싸는 인라인 표기는 입력 즉시 변환되지 않습니다. 이 경우 툴바나 본문 편집 단축키를 사용하세요.

선택 강조 단축키는 노트 본문용입니다. 표·코드블록의 별도 편집창에서는 같은 동작을 보장하지 않습니다. 현재 노트 찾기는 주 편집기를 대상으로 하며, PDF·HTML 미리보기는 해당 뷰어의 찾기를 사용하세요.

06 / WORK WITH AI

참고 자료를 연결하고 결과물 만들기

노트 옆 AI 대화에서 OpenAI 또는 Claude 계정을 연결하세요. Liberaflow 로그인과 AI 제공자 로그인은 별개이며, 모델 제공자의 이용 한도와 요금이 적용됩니다.

  1. @를 입력하고 목록에서 참고할 노트·폴더·PDF·이미지·Office 문서를 선택합니다. 파일을 끌어다 놓거나 붙여넣어 첨부할 수도 있습니다.
  2. 원하는 파일 형식과 작업을 구체적으로 요청합니다. 예: “이 회의 메모로 결정 사항과 미정 항목을 구분한 Word 문서를 만들어줘.”
  3. 결과를 미리 보고 필요한 부분을 선택해 수정 요청을 이어갑니다. 파일을 만들었다고 다른 사람에게 자동 공유되지는 않습니다.
  4. AI 작업을 되돌리면 해당 턴의 체크포인트에 포함된 보관함 파일 변경을 복구합니다.

@로 문서·폴더 연결하기

AI 입력창에서 @ 뒤에 찾을 이름을 입력하고, 목록에서 문서나 폴더를 선택하세요. 선택한 자료를 언급한 상태로 원하는 작업을 이어서 적습니다.

노트·폴더뿐 아니라 PDF·이미지·Office 문서도 참고 자료로 연결할 수 있습니다.

로그인하면 OpenRouter 모델과 Spaces 검색도 사용할 수 있습니다. 반복해서 쓰는 작업은 에이전트 스킬로 만들고 /스킬명으로 실행할 수 있습니다.

AI 응답에는 네트워크 연결이 필요합니다. 요청에 필요한 자료와 대화 맥락이 선택한 모델 제공자에게 전달됩니다.

07 / BROWSER AUTOMATION

녹화한 작업을 실행하고, 가이드로 남기기

에이전트 → Browser Automation에서 Chrome 또는 Edge 확장을 연결하세요. 클릭·입력을 녹화해 반복 실행하고, 기록한 절차를 따라 할 수 있는 가이드 문서로 만듭니다. 웹페이지에서 고른 값은 CSV·XLSX로 저장할 수 있습니다.

클릭과 입력을 반복하기

  1. 브라우저에서 작업할 탭을 연 뒤, 앱 또는 확장 팝업에서 녹화를 시작합니다. 안내를 확인하고 동의한 뒤 클릭과 입력을 기록합니다.
  2. 녹화를 마치고 저장된 단계를 확인합니다. 여러 건을 처리하려면 Excel·CSV 데이터를 불러와 열을 녹화한 입력에 연결합니다.
  3. Replay로 재생하고 실행 결과를 확인합니다.

녹화한 작업으로 가이드 문서 만들기

녹화한 순서와 설명을 마크다운 문서로 정리해, 작업을 다시 익히거나 다른 사람에게 절차를 전달할 때 활용하세요. 캡처한 화면이 있으면 문서에 함께 담습니다.

  1. 녹화한 워크플로를 연 뒤 상단 ⋮ 메뉴에서 가이드 문서 만들기 (md)를 선택합니다.
  2. 이름과 설명(선택)을 입력하고 만들기를 누릅니다. 선택한 AI로 가이드를 생성합니다.
  3. 완료되면 폴더 열기로 결과를 확인합니다. 현재 Notes 보관함의 Browser Automation 가이드 폴더에 .md 문서와 images 폴더가 저장됩니다.
  4. Notes에서 문서를 열어 확인하고 다듬습니다. 일반 마크다운 파일이므로 Obsidian에서도 열 수 있습니다.

화면 캡처가 없으면 글로만 가이드를 만듭니다. 이미지를 포함하려면 녹화 전에 확장 팝업에서 화면 캡처를 켜세요.

가이드 생성에는 워크플로 단계·기록된 입력값·URL·이미지 파일명이 선택한 AI에 전달됩니다. 가이드에 넣을 이미지 자체는 AI에 보내지 않고 로컬 문서에 저장합니다.

페이지의 값을 CSV·XLSX로 저장하기

  1. 확장 팝업의 데이터 뽑기를 열고 필요한 값을 클릭합니다. 반복 목록과 페이지 제목처럼 한 번 나오는 값을 함께 고를 수 있습니다.
  2. 앱으로 보내기를 누른 뒤 Liberaflow에 도착한 카드에서 단계로 추가를 누릅니다.
  3. 추출 단계 뒤에 파일 내보내기 단계를 추가합니다. CSV 또는 XLSX를 고르고 파일 이름·저장 위치를 확인합니다.
  4. Replay 실행 후 완료 창에서 파일명·행 수를 확인하고 파일 열기로 결과를 엽니다.

데이터 뽑기에 녹화나 입력 CSV는 필수가 아닙니다. 수집 결과는 내보낸 파일에서 확인합니다.

저장된 절차를 재사용하고, 필요한 곳에만 AI 쓰기

녹화한 클릭·입력, 데이터 뽑기와 CSV·XLSX 저장은 정해진 단계대로 실행합니다. AI가 매번 페이지를 탐색하고 판단하는 호출을 줄여, 반복 실행의 토큰 사용량을 줄일 수 있습니다.

AI는 실패 복구, 직접 추가한 AI 작업, 가이드 생성처럼 필요한 지점에 사용합니다. 일반 클릭·입력마다 내용을 AI에 보낼 필요가 줄어들어, 민감한 업무를 포함한 브라우저 자동화에서도 외부 전송 범위를 관리하기 좋습니다.

비밀번호·인증번호·카드 보안코드로 식별한 입력값은 녹화에서 제외합니다.

AI 사용과 전송 범위 조절하기

상단 ⋮ 메뉴의 실패 시 AI 자가치유 허용, 외부 AI 전송 차단, 자가치유 스크린샷 전송에서 설정을 확인하세요. AI를 사용할 때는 제공자와 목적에 따른 전송 동의를 확인합니다.

외부 AI 전송을 차단하면 가이드 생성 등 Browser Automation의 AI 기능도 사용할 수 없습니다.

개발 예정

저장한 워크플로를 AI 스킬로 호출하기

앞으로는 저장된 브라우저 워크플로를 스킬 형태로 AI 대화에서 호출할 수 있도록 연결할 계획입니다. 기록해 둔 절차를 재사용하고, 필요한 판단이나 예외 처리에 AI를 더하는 방향입니다.

화면 캡처 여부는 확장 팝업의 클릭 전후 화면 캡처·AI 자가치유 화면 캡처에서 확인하고 변경하세요. 녹화와 AI 전송은 별도 동의 절차를 따릅니다.

08 / SHARE & COLLABORATE

필요한 자료로 함께 일하기

문서 공유

Liberaflow에 로그인하고 보관함의 클라우드 동기화를 켠 뒤, 문서의 공유 창에서 사람이나 팀을 선택합니다. 공유한 노트는 작성자의 것으로 남고, 공유를 해제하면 접근을 거둘 수 있습니다.

채널에서 AI 팀원과 검토하기

  1. 팀 채널 또는 개인 채널을 만들고, 에이전트 허브에서 설정한 AI 팀원을 멤버 창의 내 팀원 초대로 추가합니다.
  2. 채널 메뉴의 내 문서 채널에 공유에서 자료를 공유한 뒤, 입력창의 @ 목록에서 문서를 선택합니다.
  3. # 목록에서 AI 팀원을 고르고 작업을 요청합니다. AI 팀원을 부르지 않은 메시지는 사람들에게만 전달됩니다.
  4. 여러 AI 팀원을 한 요청에 넣으면 함께 실행됩니다. 팀원 답변 속 멘션은 다음 팀원에게 작업을 넘길 수 있습니다.

Spaces에서 팀의 지식 찾기

Spaces에 문서를 모아 의미로 검색하고 근거와 함께 답을 받습니다. AI 대화에 지식 공간을 연결해 자료를 참고할 수 있습니다.

채널의 @ 목록에는 멤버가 접근할 수 있는 공유 문서가 표시됩니다. 채널 AI는 호출한 사람의 컴퓨터와 모델 연결로 실행됩니다.

09 / CALENDAR & TASKS

내 일정부터 함께 보는 일정까지

  1. Calendar에서 날짜를 누르고 제목·시작·종료 시간을 정해 일정을 만듭니다.
  2. Tasks의 오늘의 할일에서 할 일을 추가하고 끝낸 항목을 완료로 표시합니다. 개인 일정과 할 일은 로그인 없이 시작할 수 있습니다.
  3. 함께 보려면 로그인 후 설정 → 팀에서 팀을 만들고 멤버를 초대하거나, 설정 → 사람에서 팔로우를 요청합니다. 상대가 수락하면 연결됩니다.
  4. Calendar에서 내 일정과 같은 팀·팔로우한 사람의 공개 일정을 한 화면에 봅니다. 같은 팀이면 별도 팔로우가 필요하지 않습니다.

공개 일정은 팔로워·같은 팀원에게, 비공개 일정은 작성자와 지정한 참석자에게만 표시됩니다.

바탕화면과 프로젝트에서도

일정·할 일·프로젝트 간트 타임라인을 연결해 관리합니다. 할 일·스티키 메모·캘린더는 독립된 데스크톱 위젯으로 띄울 수 있습니다.

AI 작업 예약하기

에이전트 허브에서 한 번 또는 매일·매주 실행할 작업을 예약합니다. 앱이 켜져 있어야 실행되며, 실행 기록에서 결과와 실패 사유를 확인할 수 있습니다.

앱이 꺼져 있어 놓친 예약은 24시간 이내인 경우 다음 실행 때 처리합니다. 24시간을 넘긴 예약은 실패로 기록됩니다.

10 / STORAGE & SYNC

로컬 저장, 동기화, 공유 구분하기

기본 작업 공간은 내 컴퓨터의 보관함입니다. 클라우드 동기화는 보관함별로 켜고, 다른 사람에게 공유할 자료는 따로 선택합니다.

저장과 공유 범위
자료 동기화와 공유
노트·캔버스 동기화를 켜면 내용과 삭제가 다른 기기에 반영됩니다. 노트는 사람·팀을 지정해 공유하고, 캔버스는 공개 설정 또는 팀 공유를 사용합니다.
PDF 비공개 파일로 동기화합니다. PDF 자체의 공유 기능은 제공하지 않습니다.
HTML 비공개 파일로 동기화합니다. 멤버 공유를 선택하면 공유 시점의 사본을 전달합니다.
Office·CSV 등 다른 파일 열어볼 수 있다는 것이 자동 동기화를 의미하지는 않습니다. 보관함의 모든 파일이 클라우드로 동기화되는 것은 아닙니다.

노트에 삽입한 이미지도 동기화됩니다. 보관함에 따로 놓은 이미지 파일 전체가 동기화되는 것은 아닙니다.

삭제와 복구

클라우드 동기화한 노트·캔버스는 삭제가 다른 기기에도 반영되며 30일 안에 복구할 수 있습니다. PDF·HTML은 클라우드에서도 바로 삭제되고 별도 휴지통이 없습니다.

로컬 보관함의 휴지통·백업은 클라우드 복구와 별개입니다. 중요한 원본은 별도로 백업하고, 삭제할 때는 파일 종류와 동기화 상태를 확인하세요.
