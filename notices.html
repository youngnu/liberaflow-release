2026.10.28 / 1.5.2

1.5.2 에서 바뀐 점

1.5.1 이후 바뀐 점입니다. macOS 는 1.4.9 다음 판이 1.5.2 라서, 아래 Windows 1.5.0·1.5.1 의 변경도 함께 들어 있습니다.

처음 쓰는 분

  • 로그인 화면에서 '로그인 없이 계속'을 눌러 보관함 고르기 화면으로 돌아갈 수 있습니다.
  • Mac 에서 앱을 켜자마자 알림 허용을 묻지 않습니다. 보관함을 고른 뒤 알림이 오는 경우를 먼저 보여 드리고, '알림 켜기'를 누를 때만 묻습니다.
  • 왼쪽 막대의 아이콘에 마우스를 올리면 이름이 보입니다.
  • 설정 → 공지사항을 누르면 이 페이지가 열립니다.

AI 팀원과 채널

  • 코딩 프로젝트에서 AI 팀원이 내 작업 폴더를 건드리지 않고 따로 마련한 폴더에서 일합니다. 바뀐 내용은 채널의 PR 카드에서 보고 합칩니다.
  • AI 대화에서 캘린더 일정과 예약 AI 작업을 만들고, 고치고, 취소할 수 있습니다.
  • 에이전트 허브의 플러그인으로 AI 가 GitHub·Supabase·Stripe 를 직접 쓰도록 연결합니다.
  • 채널 '내 보관함' 미리보기에서 ←·→ 키나 마우스 옆 단추로 이전·다음 문서를 넘겨 봅니다.

노트와 문서

  • 보관함의 옛 한글 문서(.hwp)를 처음 한 번 물어본 뒤, AI 가 읽고 고칠 수 있는 .hwpx 로 바꿔 둡니다.
  • 긴 노트를 열 때 오래 멈추던 문제를 줄였습니다.
  • 캘린더 메모가 보관함의 Memo 폴더에 마크다운 파일로 저장되어 노트 화면에서도 보입니다.
  • 다른 사람이 공유한 노트를 다시 열면 최신 내용을 받아 오고, 저장할 때 그 사람의 수정을 덮어쓰지 않습니다.

캘린더와 알림

  • '오늘의 할일'에서 새 할 일을 창 없이 바로 입력합니다. 같은 일정의 할 일은 누가 체크하든 모두에게 완료로 보입니다.
  • 프로젝트 간트를 1주·2주·4주 단위로 볼 수 있습니다.
  • 내일 일정 요약이 항목별로 정리되고, 협업자가 고친 일정이 모두의 캘린더와 알림에 반영됩니다.
  • Windows 알림에 앱 이름이 제대로 나오고, 일정 알림을 누르면 그 일정으로 이동합니다.

고친 문제

  • Windows 에서 채팅 속 파일 링크를 누르면 앱이 꺼지던 문제
  • 회사 네트워크에서 채널 연결이 끊겼다는 표시가 새로 고침할 때까지 남던 문제
  • 표 칸과 HTML 표 안의 수식이 저장할 때 사라지던 문제
  • 보관함을 바꾼 뒤 '@' 파일 후보가 이전 보관함에 머물던 문제

2026.10.13 / WINDOWS 1.5.1

Windows 1.5.1 배포

1.5.0 에서 발견된 문제를 고친 판입니다.

  • 채널에 다녀오면 보관함이 계정 기본 보관함으로 바뀌던 문제를 고쳤습니다.
  • 파일 탐색기에서 만든 폴더·파일이 사이드바에 보이지 않거나 맨 위 폴더에 잘못 보이던 문제를 고쳤습니다.
  • Glass 배경에서 창 뒤가 어두우면 보조 글자와 아이콘이 잘 보이지 않던 문제를 고쳤습니다.
  • 다른 프로그램이 열고 있는 문서를 고치지 못할 때 영어 오류 대신 한국어 안내를 보여 줍니다.
2026.10.12 / WINDOWS 1.5.0

Windows 1.5.0 배포

1.4.9 이후 크게 바뀐 점입니다.

채널

  • 채널이 Local 과 Cloud 두 공간으로 나뉩니다. Local 은 로그인 없이 이 컴퓨터에서 AI 팀원과 일하는 채널이고, Cloud 는 팀과 함께 쓰는 채널입니다.
  • 채널에 코딩 프로젝트 폴더를 연결하면 파일과 변경 내용을 보고, AI 팀원이 그 폴더에서 일합니다.
  • 채널 메모에 팀이 정한 조건·결정·진행 상황을 남기고, AI 팀원도 함께 읽고 씁니다.

문서

  • 엑셀·워드·파워포인트 미리보기에서 내용을 바로 고치거나, 주석을 달아 AI 에게 수정을 맡길 수 있습니다.
  • PDF 와 그림에서도 영역을 끌어 골라 주석을 보낼 수 있습니다. AI 는 원본을 그대로 두고 옆에 사본을 만들어 고칩니다.
  • AI 팀원이 한글(HWPX) 문서의 표와 글상자를 더 안정적으로 만들고 고칩니다.
  • 코드 파일을 앱 안 코드 보기로 열고, 사이드바의 '파일 위치 열기'로 실제 폴더를 엽니다.

AI 연결

  • 설정 → 내 연결에 내 OpenRouter 키를 넣어 OpenRouter 모델을 씁니다. 대화·AI 팀원·예약 작업이 그 키로 돌아갑니다.

캘린더

  • 공휴일을 표시합니다. 나라는 기기 지역을 따르며 설정에서 바꿀 수 있습니다.
  • 왼쪽 패널에서 캘린더·프로젝트·메모를 오가고, 맞춤 보기에서 원하는 패널을 자유롭게 배치합니다.
  • 매일 체크하는 루틴을 만들 수 있습니다.
